# 📂 Projects

## 🪟 AD Windows Inventory

PowerShell-based inventory collection for Windows computers in an Active Directory environment.

The script automatically retrieves computers from Active Directory and remotely collects hardware and operating system information.

### Collects

- Computer name
- Manufacturer
- Model
- RAM
- Operating System
- OS Version
- CPU
- BIOS Serial Number
- Disk information
- Disk size
- Free disk space

### Technologies

`PowerShell` • `Active Directory` • `WinRM` • `CIM` • `CSV`

[![Repository](https://img.shields.io/badge/View_Repository-181717?style=for-the-badge&logo=github)](https://github.com/RYLE-307/AD-Windows-Inventory)
